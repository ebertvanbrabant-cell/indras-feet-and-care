# Indra's feet & care

Website van Indra's feet & care, esthetische pedicure aan huis.

- `site/`: de publieke bestanden van de website.
- `wrangler.jsonc`: instellingen voor Cloudflare Workers (statische site).

Cloudflare bouwt en zet de site automatisch online bij elke wijziging op `main` (deploy: `npx wrangler deploy`).
